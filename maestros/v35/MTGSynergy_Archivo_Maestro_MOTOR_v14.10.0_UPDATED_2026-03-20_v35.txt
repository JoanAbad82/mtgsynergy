ACTUALIZACIÓN (2026-02-18) — MOTOR: SPS v1.1 (Structural Power Score) + clamp defensivo
=====================================================================

OBJETIVO
Añadir una métrica global “Structural Power Score” (SPS) sin cambiar la semántica del motor existente:
- Se computa tras structural summary y edges.
- Se adjunta a `StructuralSummary` como campos opcionales + breakdown para UI.

ARCHIVOS (engine)
- src/engine/structural/sps.ts
  - export const SPS_ALPHA = 0.15
  - export function computeStructuralPowerScore(summary, edges)
    Devuelve:
      { sps: number, breakdown: { sumScore, B, density, F_dens, H_hat, F_roles, u, F_util } }

- src/engine/domain/types.ts
  - `StructuralSummary` añade:
    - structuralPowerScore?: number
    - structuralPowerBreakdown?: { sumScore, B, density, F_dens, H_hat, F_roles, u, F_util }

- src/engine/analyzer/index.ts
  - Tras `computeStructuralSummary(deckState)`:
    - `const spsResult = computeStructuralPowerScore(summary, deckState.edges ?? [])`
    - adjunta score + breakdown al summary

FÓRMULA SPS v1.1 (raw, sin normalización 0–100)
SPS_raw = B * F_dens * F_roles * F_util

- sumScore = Σ score_e  (sobre edges)
- B      = 10 * ln(1 + sumScore)
- F_dens = 1 + sqrt(max(0, density))
- H_hat  = entropía normalizada roles no-LAND
  - p_r = c_r / Σ c_r (roles activos, excluye LAND)
  - H = -Σ p_r log2 p_r
  - H_max = log2(|R|) con |R| = nº roles activos (excluye LAND)
  - H_hat = H / H_max (si |R|>1)
- F_roles = 1 + alpha * H_hat  (alpha=0.15)
- u = c_UTILITY / Σ c_r (roles no-LAND)
- F_util:
  - si u <= 0.30 => 1
  - si u > 0.30 => 1 - 0.25*(u - 0.30)/0.70
  - clamp defensivo: F_util = max(0, F_util_raw)

TESTS (engine, puros)
Archivo: src/engine/__tests__/sps_v1_1.test.ts
- “case A” (mazo ejemplo) sin penalización util:
  - valida u≈0.1875, F_util=1, B≈50.2, F_dens≈1.327, F_roles≈1.148, SPS≈76.5
- “case B” con penalización util:
  - valida que F_util baja y se usa en el producto
- Test defensivo:
  - u extremo (UTILITY >> resto) => F_util no-negativo (clamp)

NOTA DE ROBUSTEZ
- El clamp no era estrictamente necesario con la fórmula actual (no hace negativo en u∈[0,1]), pero se mantiene como hardening defensivo frente a datos anómalos.
