RESULTADO TÉCNICO FIJADO
=====================================================================

La microfase mejora el copy visible del panel semántico para explicar mejor las señales locales de una sola carta.

Antes:

- El panel indicaba que estas señales eran relaciones internas de una carta y no sinergias entre cartas distintas.

Después:

- El panel aclara que estas señales:
  - se detectan dentro de una misma carta,
  - pueden verse como carta → misma carta,
  - tienen puntuación 0,
  - no cuentan como conexión principal,
  - no aumentan SOS,
  - no aumentan SPS,
  - sirven como evidencia local.

Texto nuevo fijado en SemanticOverlayPanel:

- “Estas señales se detectan dentro de una misma carta. Pueden verse como carta → misma carta, tienen puntuación 0, no cuentan como conexión principal, no aumentan SOS y no aumentan SPS; sirven como evidencia local.”

=====================================================================
LECTURA CANÓNICA
=====================================================================

La capa de superposición semántica puede mostrar señales locales aunque no aumenten SOS ni SPS.

Lectura correcta:

- “Conexiones principales detectadas” corresponde a edges con score positivo.
- “Señales locales de una sola carta” corresponde a señales internas, normalmente self-edges.
- Los self-edges score 0 son evidencia semántica local.
- No deben confundirse con relaciones estructurales.
- No deben usarse como justificación automática para modificar SPS.
- La UI ahora explica explícitamente esa frontera.
