===================================================================== ADDENDA H8 — MC‑SSL (Monte Carlo) panel experimental
Fecha actualización: 2026-02-19
=====================================================================

Objetivo
-   Exponer un panel experimental para estabilidad/robustez del Structural Power Score (SPS) vía MC‑SSL v1.
-   100% client‑side, sin backend, determinista por seed.

Feature flag (URL)
-   Activación: mc=1.
-   Overrides: mcN (iterations), mcSeed (seed).
-   Defaults: iterations=1000, seed=1. robust_p=0.1 en el motor.

Comportamiento UI
-   Si mc=1: se muestra panel "Monte Carlo (experimental)".
-   Estados: idle | running | done | error.
-   SSR/hydration safe: no depende de window en el estado inicial; parseo en mount.
-   Race‑safe: si cambian parámetros/mazo durante la ejecución, resultados antiguos se ignoran (runId guard).
-   Actualización por navegación: escucha popstate para cambios de query params.

Salida mostrada
-   base SPS
-   robust_sps (percentil robusto definido por motor)
-   fragility
-   effective_n / requested_n / no_op
-   seed / iterations
-   warnings (si existen)

Contrato de cálculo (importante)
-   En cada iteración, SPS se recomputa con el pipeline real:
    generateEdges(entries) → computeStructuralSummary(DeckState) → computeStructuralPowerScore(summary, edges).
-   Se aplica getSpsNumber(x) para soportar SPS como número o como objeto {sps}.
