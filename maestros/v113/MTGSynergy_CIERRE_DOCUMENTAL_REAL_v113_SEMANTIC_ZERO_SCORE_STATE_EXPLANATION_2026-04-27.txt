=====================================================================
RESULTADO TÉCNICO FIJADO
=====================================================================

La UI distingue ahora tres estados visibles:

1. Señal/conexión con fuerza positiva:

   Condición:

   - metrics.SOS > 0
   - o mainEdges.length > 0

   Label:

   - “✅ Señal encontrada (experimental)”

2. Señal local sin fuerza semántica positiva:

   Condición:

   - metrics.SOS === 0
   - mainEdges.length === 0
   - weakEdges.length > 0

   Label nuevo:

   - “ℹ️ Señal local encontrada (sin fuerza semántica positiva)”

3. Sin señal:

   Condición:

   - metrics.SOS === 0
   - mainEdges.length === 0
   - weakEdges.length === 0

   Label:

   - “⚠️ Sin señal (experimental)”

Cambio técnico principal:

- getSignalStatus pasa de depender de visibleEdgesCount a distinguir:
  - mainEdgesCount
  - weakEdgesCount

Lectura correcta:

- Una señal local score 0 ya no se presenta como señal positiva genérica.
- Una conexión principal score > 0 sigue apareciendo como señal encontrada.
- SOS positivo sigue apareciendo como señal encontrada.
- La ausencia total de fuerza/señales sigue apareciendo como sin señal.
